# Experimentelle isolierte Erweiterungen – Iteration 67

Ein fremdes Python-Skript wird **niemals** in den laufenden Programmprozess geladen. Diese experimentelle Schnittstelle verlangt ein kleines Paket mit `plugin.json` und `main.py`. Das Paket darf nur streng bekannte Eigenschaften und Fähigkeiten enthalten, derzeit Text-Eingabe (`read_input`) und Standardausgabe (`write_stdout`). Kein Zugriff auf das persönliche Datenverzeichnis, auf Netzwerk, Shell, andere Programme oder auf das Desktop-Fenster ist vorgesehen.

Der separate Linux-Prozess wird nur nach ausdrücklicher Zustimmung über **bubblewrap (bwrap)** gestartet. Fehlt eine funktionierende Linux-Namensraum-Isolierung, wird der Start verweigert. Die Paketdateien werden im separaten Prozess nur lesend eingebunden; der ausführende Prozess besitzt keinen HOME-Zugriff auf das Konto. Die Laufzeit ist auf maximal 20 Sekunden begrenzt. **Wichtig:** Dies ist ein Prüfkandidat, kein vollständiges Sicherheitssystem für beliebige feindliche Programme. Vor einer Freigabe fehlen unter anderem Ressourcenbegrenzung, echte Berechtigungsdialoge in der Oberfläche, Signatur-/Herkunftsprüfung und ein nachgewiesener Isolationsangriffstest. Die Anwendung startet **keine** solchen Zusatzprogramme automatisch. Eine vollständige automatische CI und später die vereinbarte Kubuntu-Gesamtabnahme sind erforderlich.
