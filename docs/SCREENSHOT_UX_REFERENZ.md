# Screenshot-Referenz – 09.09.2026

Die reale Kubuntu-Oberfläche wurde anhand von drei Nutzer-Screenshots bewertet:

1. **Songtexteditor** – Metadaten oben, Songbereiche links, Textarbeit Mitte, Gesamtvorschau rechts.
2. **Songbibliothek** – Suche/Filter oben, Ergebnistabelle Mitte, sichere Aktionen unten.
3. **Dashboard** – Header, Schnellkacheln, Navigation, Projekt-Notiz, Startkarte, Vorgaben, geplante Funktionen und Statusleiste.

## Abgeleitete Designregeln

- Lesbarkeit geht vor maximaler Informationsdichte.
- Fensterbreite muss nutzbaren Elementen zugutekommen, nicht leerer Tabellenfläche.
- Lange Navigations- und Songbereichsnamen dürfen nicht unnötig abgeschnitten werden.
- Akzentfarbe kennzeichnet Hierarchie und Interaktion; sie umrahmt nicht jede Fläche gleich stark.
- Hinweistext muss deutlich lesbar bleiben und mindestens den automatisiert geprüften Kernkontrast einhalten.
- Zoom vergrößert nicht nur Schrift, sondern reserviert auch mehr Breite für zentrale Bedienelemente.
- Splitter und Scrollleisten müssen als bedienbare Elemente sichtbar bleiben.
- Responsive Anpassung darf keine Daten- oder Fachlogik verändern.

Diese Datei enthält bewusst keine Screenshots oder Binärdateien; das Repository bleibt frei von lokalen Screenshot-Artefakten.
